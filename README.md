# Image Classification using ML (CNN) 🖼️

This project is a Tier-2 task for the Devotics Industrial Experience Program. It uses a Convolutional Neural Network (CNN) built with TensorFlow and Keras to classify handwritten digits from the MNIST dataset.

## Features
- Uses the MNIST dataset (handwritten digits 0-9).
- Built using a Sequential CNN model with Convolutional (Conv2D) and MaxPooling layers.
- Data normalization for faster and more accurate training.
- Visualizes model predictions alongside actual images using Matplotlib.

## Requirements
- Python 3.x
- TensorFlow
- Matplotlib
